# Reflexión final – Semana 16

Durante el desarrollo de nuestra aplicación de gestión de tareas en Flutter, comprendimos la importancia de realizar pruebas para garantizar su correcto funcionamiento.

Uno de los errores más importantes fue que las tareas no aparecían ordenadas cronológicamente, lo cual afectaba la organización de la información.

Una prueba funcional temprana que verificara el orden de las tareas habría permitido detectar y evitar este problema antes.

También identificamos errores relacionados con las descripciones vacías y los títulos duplicados, que solucionamos mediante validaciones.

Las pruebas unitarias y de widgets nos ayudaron a comprobar el funcionamiento de diferentes componentes de la aplicación.

Además, aprendimos a utilizar Firebase para gestionar usuarios y almacenar información, y GitHub para colaborar y controlar los cambios del proyecto.

Esta experiencia nos enseñó que realizar pruebas continuamente permite detectar errores a tiempo y desarrollar aplicaciones más confiables.
